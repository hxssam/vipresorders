## Админ-панель (кнопка ⚙)
Пароль по умолчанию: `Vip#4827` — замените сразу.
- Команда (имя + должность) добавляется только в админ-панели.
- Удаление товаров и групп доступно только после входа и включения «Режим удаления».
- Чтобы изменения увидели все телефоны: в панели нажмите «Скопировать config.js» и вставьте текст в файл `config.js` на GitHub.
- Смена пароля: введите новый пароль → «Задать пароль» → «Скопировать config.js» → вставьте в GitHub.

Данные (черновик, каталог, история) хранятся в браузере устройства.
