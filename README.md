# ВИАЙПИ РЕСТОБАР КУХНЯ — заказ, заготовки и график (онлайн)

Вкладки: Заказ · Заготовки (общий список для всех поваров) · График (рабочие дни отмечены буквой «Р») · Списание.

Файлы: `index.html`, `styles.css`, `app.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `icons/`, `firebase-rules.json`, `SETUP-AR.md`.

Списание ведётся по товарам общего каталога с количеством, причиной и комментарием; сегодняшние записи автоматически добавляются в копируемый заказ на завтра. Отметки выполненных заготовок сохраняются в общем справочнике, откуда их можно добавить на новый день. Справочник можно пополнять, редактировать и очищать; дни подготовки можно закреплять и быстро открывать из списка, а их значки видны в календаре графика. В расписании у каждого повара свой цвет; имя Хоссам всегда первым.

Нажмите на статус вверху («● онлайн») — откроется диагностика связи.
Правила Firebase: после обновления вставляйте содержимое `firebase-rules.json` в Realtime Database → Rules → Publish.
