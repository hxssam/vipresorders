# ВИАЙПИ РЕСТОБАР КУХНЯ — заказ, заготовки и график (онлайн)

Вкладки: Заказ · Заготовки (общий список для всех поваров) · График (рабочие дни отмечены буквой «Р») · Списание.

Файлы: `index.html`, `styles.css`, `app.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `logo.png`, `logo-ink.png`, `icons/`, `firebase-rules.json`, `SETUP-AR.md`.

Списание ведётся по товарам общего каталога: для каждой записи можно выбрать количество, единицу измерения, причину и комментарий; порча и повреждение — разные причины. Список за день можно скопировать или отправить отдельно, даже если заказов нет; сообщение сгруппировано по тем же товарным категориям, что и заказ. При копировании заказа на завтра сегодняшние списания добавляются в него автоматически. Отметки выполненных заготовок сохраняются в общем справочнике, откуда их можно добавить на новый день. Справочник можно пополнять, редактировать и очищать; дни подготовки можно закреплять и быстро открывать из списка, а их значки видны в календаре графика. В расписании у каждого повара свой цвет; имя Хоссам всегда первым.

Нажмите на статус вверху («● онлайн») — откроется диагностика связи.
Правила Firebase: после обновления вставляйте содержимое `firebase-rules.json` в Realtime Database → Rules → Publish.

**v8.6:** **Отдельная отметка «Подано» в «Банкет» (только для шефа).** У каждого блюда банкета теперь две независимые отметки: слева зелёная — «приготовлено» (её ставит повар, как раньше; видно имя и время), справа золотая — «🍽 Подано» (ставит шеф, когда реально отдал блюдо гостям). Отметка «Подано» завершает задачу: блюдо уходит в группу «✓ Подано · N» внизу, строка становится золотой, под коробкой — время подачи. Список «Осталось подать» остаётся в порядке времени подачи; готовые поварами строки зелёные, поэтому сразу видно, что можно нести. Над списком — легенда, в карточке банкета — «Готово X/N · Подано Y/N», на полосе прогресса — две части (готово / подано), на чипах банкетов и вкладках — «5/6 🍽2». Кнопка «🍽 Подать всё готовое · N» (с подтверждением) отмечает все блюда, которые повара уже приготовили. Если шеф подал блюдо, которое повар не отметил, оно считается приготовленным (бледная пунктирная ✓), но данные повара не подменяются. Повторное нажатие снимает «Подано». Поварам окно «Подано» видно, но не нажимается (подсказка «Подачу отмечает шеф»); шеф определяется по устройству, где выполнен вход в админ-панель (токен хранится, поэтому после перезапуска работает сразу, даже без интернета). Подано-блюда не переносятся на следующий день и не попадают в «осталось с сегодня» в тексте «Завтра». Новые поля блюда: `sd` (подано), `sa` (время), `sb` (кто). **Правила Firebase не меняются.**
