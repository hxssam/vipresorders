# ВИАЙПИ РЕСТОБАР КУХНЯ — заказ, заготовки и график (онлайн)

Вкладки: Заказ · Заготовки (общий список для всех поваров) · График (рабочие дни отмечены буквой «Р») · Списание.

Файлы: `index.html`, `styles.css`, `app.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `icons/`, `firebase-rules.json`, `SETUP-AR.md`.

Списание ведётся по товарам общего каталога: для каждой записи можно выбрать количество, единицу измерения, причину и комментарий; порча и повреждение — разные причины. Список за день можно скопировать или отправить отдельно, даже если заказов нет; сообщение сгруппировано по тем же товарным категориям, что и заказ. При копировании заказа на завтра сегодняшние списания добавляются в него автоматически. Отметки выполненных заготовок сохраняются в общем справочнике, откуда их можно добавить на новый день. Справочник можно пополнять, редактировать и очищать; дни подготовки можно закреплять и быстро открывать из списка, а их значки видны в календаре графика. В расписании у каждого повара свой цвет; имя Хоссам всегда первым.

Нажмите на статус вверху («● онлайн») — откроется диагностика связи.
Правила Firebase: после обновления вставляйте содержимое `firebase-rules.json` в Realtime Database → Rules → Publish.

**v8.0:** новый дизайн (индиго-фиолетовая палитра, тёмная тема, анимации: плавающий индикатор вкладок, появление экранов и строк, «пружинящие» галочки, плавные диалоги; отключаются при «Уменьшить движение» в системе); новые «системные» звуки — колокольчики и мягкие сигналы вместо игровых, громкие; вкладка **«Кабинет»** — повар выбирает имя, вводит пароль от шефа и сам записывает/правит часы своих смен; «Закрыть» сразу выходит. Вход живёт только в памяти этого экрана: не сохраняется на телефоне, закрывается при смене вкладки, через 3 мин без действий и через 30 с в фоне — на другом телефоне чужой кабинет увидеть нельзя. Руководитель видит все часы, введённые поварами (👤), и может зафиксировать день (🔒) — тогда повар его не изменит. «Ближайшие смены» свёрнуты; «Завтра на смену» всегда показывает имена (из сохранённого состава, а если его нет — из графика «Р»), в том числе в установленном приложении. Исправлена гонка синхронизации: изменение, сделанное в момент отправки предыдущего, могло дойти до других телефонов с задержкой до 30 с. Правила Firebase изменены (повар может записывать только `acct/<ключ>/in/<дата>` с часами 0–24) — **обязательно опубликуйте заново**.
