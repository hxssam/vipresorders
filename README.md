# ВИАЙПИ РЕСТОБАР — заказ кухни, заготовки и график (онлайн)

Вкладки: Заказ · План и заготовки (общий список для всех поваров) · График (рабочие дни отмечены буквой «Р»).

Файлы: `index.html`, `styles.css`, `app.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `icons/`, `firebase-rules.json`, `SETUP-AR.md`.

Отметки выполненных заготовок сохраняются в общем справочнике, откуда их можно добавить на новый день. В расписании у каждого повара свой цвет; имя Хоссам всегда первым.

Нажмите на статус вверху («● онлайн») — откроется диагностика связи.
Правила Firebase: после обновления вставляйте содержимое `firebase-rules.json` в Realtime Database → Rules → Publish.
